怎样读这份报告

  • PASS：全部必需场景具备当前源码的原生结果、绑定回执及已审核运行截图。
  • PARTIAL / UNRUN：场景或证据待补。仅 DOM 参考与历史截图不贡献当前原生通过。
  • REWORK / BLOCKED：场景失败、运行截图需返工，或执行受阻；失败与重试保留。

导出按钮保存当前平台全部页面、场景与状态。生成器读取清单，不执行测试或替作者审图。数据模式和设备范围以各次实际回执为准。
