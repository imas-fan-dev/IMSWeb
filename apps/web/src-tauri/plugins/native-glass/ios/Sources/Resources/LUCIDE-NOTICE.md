# Lucide assets

The seven PDF assets in `Lucide.xcassets` are generated from Lucide 1.25.0 to match the `lucide-react` version used by IMSWeb's Web fallback. The tab bar uses `house`, `users`, `map-pinned`, `book-open-text`, and `circle-user`. The catalog also contains `calendar-days` and `layout-grid`.
