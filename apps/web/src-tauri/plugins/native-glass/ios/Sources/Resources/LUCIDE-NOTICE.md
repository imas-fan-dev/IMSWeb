# Lucide assets

The PDF assets in `Lucide.xcassets` are generated from Lucide 1.25.0 to match the `lucide-react` version used by IMSWeb's Web fallback. The native tab bar uses `house`, `users`, `map-pinned`, `book-open-text`, and `circle-user`. The catalog also contains `calendar-days` and `layout-grid`.

The native glass map controls draw `menu`, `x`, `map`, `list-filter`, `building-2`, `credit-card`, `user-round`, `info`, `locate-fixed`, `loader-circle`, and `refresh-cw`. Regenerate those imagesets from `apps/web` with `node scripts/generate-lucide-xcassets.mjs`.
