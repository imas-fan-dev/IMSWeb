# Lucide assets

The seven PDF assets in `Lucide.xcassets` are generated from Lucide 1.25.0 to match the `lucide-react` version used by IMSWeb's Web fallback. The current tab bar uses `house`, `calendar-days`, `layout-grid`, `map-pinned`, and `circle-user`; `book-open-text` and `users` remain available for older generated projects.
