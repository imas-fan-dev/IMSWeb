## 原始失败

[CI 38344835042](https://github.com/imas-fan-dev/IMSWeb/actions/runs/38344835042/job/115123785552) 第一次运行对应提交 `447f2323a6ef28931b80e73750336b710ea21e49`。Web 全量单测 1642 项通过、1 项失败；失败用例为 `keeps the exchange map native glass light in dark mode`。

测试等待 DOM 导航消失后立即断言原生更新调用，收到 `undefined`，说明断言执行时没有更新调用。前面的安装配置断言已经通过。DOM 的隐藏来自渲染，原生更新来自另一个 `useEffect`；两者需要各自等待。组件和测试在 `375820be` 与 `447f2323` 中的 Git blob 相同，不能将这个问题归因于本次提交对底栏的修改。原始文件在本机定向运行 11 次均为 9/9 通过，未复现 CI 的具体触发条件。
