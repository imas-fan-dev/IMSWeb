# 社区动态固定高度列表技术设计

## 设计边界

本任务只调整公开 `/events` 列表的条目与加载骨架。Web、Tauri App 和桌面端继续共用 `EventRow` 与 `EventsSkeleton`，不改变 API、路由、分页、缓存、详情页或首页动态组件。

不修改全局设计 token、`app.css`、CMS 数据模型或虚拟列表的滚动所有权。实载条目、加载骨架和虚拟列表估高统一从 `176px` 收紧为 `144px`。

## 条目结构

列表条目继续使用双栏媒体布局：左侧为固定比例封面概览，右侧为文本信息。条目使用更紧凑的 `12px` 内边距；移动端封面轨道保持 `6.5rem`，`sm` 以上从 `10.5rem` 收紧为 `9rem`，使 `4:3` 封面能够完整放入 `144px` 行高。移动端间距收紧为 `12px`，`sm` 以上使用 `16px`。

右侧内容改为一个整体垂直居中的信息块：

1. 标题是第一行的唯一内容，限制为一行，不与分类或日期并排。
2. `社区动态` 或 `具体活动` 作为紧凑标签单独显示在标题下方、元信息上方，并在所有输入设备上保持可见。
3. 摘要不在列表中渲染，完整内容留在详情页。
4. 所有视口中的发布者、发布日期和可选联系方式分别占一行，避免字段横向争抢；发布日期保留在垂直居中的主信息块内。
5. 标题、发布者和联系方式使用单行省略；发布日期保持完整可读。
6. 没有联系方式时不渲染空行，较短的信息块仍按条目中心对齐，不通过占位行制造空白。

左侧封面继续使用 `4:3`、`object-cover` 和现有焦点裁切，但不再承载分类浮层。右侧标签使用现有语义颜色、较小字号和紧凑内边距，避免新增全局 token；标题、标签与元信息通过间距和字色建立层级，不保留占用高度的横向分隔线。

## 固定高度与虚拟列表

- 实载条目改用 `h-36`，即 `144px`，比当前减少 `32px`。
- `EventsCenter` 的虚拟列表估高同步改为 `144px`，运行时测量和 overscan 行为不变。
- 条目使用固定行高和内部溢出约束，任何文本或图片都不能改变外部高度。
- 加载骨架复用相同的 `144px` 行高、媒体轨道、间距和垂直居中方式，并用与实载内容对应的标题及元信息占位行表达真实密度。
- 图片继续保留固定宽高比和预留空间，延迟加载前后不得改变条目或滚动位置。

## 响应式行为

- 320px 与 390px：标题限制为一行；元信息纵向排列，使每个字段获得完整文本列宽。字体和图标不能缩小到影响可读性。
- `sm` 以上继续使用 `9rem` 封面轨道和更宽文本列自然减少省略；发布者、日期和可选联系方式在所有断点保持独立行，不另建桌面专用组件。
- 条目、封面和文字块的中心线通过几何断言验证；不依赖截图主观判断对齐是否正确。
- 所有视口继续使用 App 安全区和页面现有宽度约束，不新增全局边距规则。

## 可访问性与交互

整行继续由 `NavigationLink` 导航到详情。语义上的 `article`、标题层级、焦点环、按压反馈和分类文字保持不变，不在整行链接内部加入联系方式链接。

被省略的发布者和联系方式继续保留文本属性供桌面辅助查看，但触屏端查看完整内容的可靠路径是进入详情页。日期在 DOM 中仍位于元信息顺序内，只改变桌面视觉定位；日期、图标和文本需要保持可读的对比度与间距。

## 测试设计

### 单元测试

扩展 `events-list.test.tsx`，固定以下行为：

- 条目与骨架都使用 `144px` 行高和相同媒体轨道。
- 标题限制为一行，摘要不再渲染。
- 分类标签位于右侧标题下方，左侧封面不再包含该标签。
- 右侧信息块垂直居中。
- 发布者、日期和联系方式在所有视口中是独立行，不存在字段互相压缩的横向布局。
- 长文本仍有明确的换行或省略约束，分类标签在所有输入设备上默认可见。

### 浏览器测试

扩展现有社区动态 Web 与 App E2E，在 320px、390px 和代表性桌面视口验证：

- 多个条目外部高度均为 `144px`。
- 封面中心、文字块中心与条目中心的偏差处于稳定的小范围内。
- 分类标签显示在右侧文字区域，封面上没有分类浮层。
- 发布者、日期和联系方式均有可见文本宽度；日期不遮挡内容或分隔线；页面无横向滚动、重叠或越界。
- 短内容、长内容和无联系方式条目均保持固定高度。
- 延迟封面加载前后的条目位置与窗口滚动位置变化不超过 `2px`。
- 保存移动端和桌面端截图供人工核对。

## 兼容与回滚

本任务没有数据库、网络协议或路由迁移。实现应集中在 `events-list.tsx` 及其直接测试；如浏览器几何断言需要测试数据或辅助函数，可小范围调整现有 Events E2E。

回滚时，实载条目、加载骨架和虚拟列表估高必须作为一组恢复到 `176px`，避免结构与滚动估算不一致。回滚不需要迁移缓存或持久化滚动状态。
