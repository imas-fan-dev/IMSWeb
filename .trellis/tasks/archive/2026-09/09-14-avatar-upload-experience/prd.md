# 统一头像上传组件体验

## Goal

让用户在 App、移动 Web 和桌面 Web 中都能直观地查看、选择、预览、上传、替换或移除自己的头像。三端共享同一套行为和状态语义，具体布局可随可用空间调整。

## Background

- 三端目前共用 `ProfileEditor` 和 Platform 头像 API；App 使用独立堆栈布局，移动 Web 与桌面 Web 使用同一响应式工作区。
- `ProfileEditor` 当前只显示文件选择控件、上传按钮和条件式移除按钮，不显示当前头像或待上传图片预览（`apps/web/app/pages/community/exchange/me/profile-editor.tsx:198`）。
- 通用 `FileUploadControl` 已支持点击选取、桌面拖放、已选文件清除、准备中和上传中状态（`apps/web/app/components/shared/file-upload-control.tsx:68`）。
- iOS App 通过原生图片准备流程选择并压缩图片；Android 与普通 Web 使用浏览器文件选择。现有上传上限为 5 MiB。
- App 资料页会隐藏 Web 侧栏，因此无法依靠侧栏头像表达当前值和上传结果；头像组件本身必须具备完整反馈。
- `09-14-avatar-display-after-upload` 已负责上传后的会话同步、受保护头像读取、跨账户竞态和存储访问安全。本任务不重复这些修复。

## Requirements

- R1. App、移动 Web 和桌面 Web 必须共用同一头像上传核心组件、校验规则、操作状态和文案语义。
- R2. 组件必须显示当前头像；没有头像或图片加载失败时使用现有首字母 fallback。
- R3. 选图后必须进入固定 1:1 的手动裁剪流程，支持拖动定位和缩放，并显示圆形结果预览；确认裁剪后仍需由用户明确上传。重新选择、取消裁剪或取消暂存不得修改服务端头像。
- R4. 上传成功后，组件必须立即显示服务端返回的新头像并清除暂存状态；上传失败时保留可重试的待上传图片和明确错误反馈。
- R5. 替换、移除、准备、上传、成功、失败、只读和冲突状态必须直观可辨，并阻止重复提交或互相冲突的操作。移除服务端头像前必须经过明确确认。
- R6. 桌面端可保留拖放和较宽的并排布局；移动 Web 与 App 使用适合触控和窄屏的纵向布局。布局差异不得改变操作顺序、结果或术语。
- R7. 所有按钮必须使用项目现有 UI 组件和 Lucide 图标，具备可访问名称、键盘焦点、禁用状态和足够的触控区域。
- R8. 继续使用现有 `useAppPreparedImage`、Platform API facade、5 MiB 限制、乐观并发、认证和私有媒体读取机制。
- R9. 普通 Web、跨源 Bearer App 和外部 OAuth 头像的读取规则保持不变；不得把 Platform 凭据发送给第三方图片地址。
- R10. 增加单元与浏览器回归测试，覆盖三类布局、当前头像、选图预览、重新选择、取消、上传成功/失败、移除、只读和加载失败 fallback。

## Acceptance Criteria

- [x] AC1. 有头像的用户进入资料编辑页时，三端都能在上传区域直接看到当前头像；无头像或加载失败时显示首字母 fallback。
- [x] AC2. 选图后，用户可以在固定 1:1 的圆形预览中拖动和缩放构图，确认裁剪后仍可重新选择或取消；这些操作不修改服务端数据，只有明确执行上传才会提交。
- [x] AC3. 上传期间无法重复上传、移除或保存冲突的资料操作，界面持续显示正在处理的对象和状态。
- [x] AC4. 上传成功后无需刷新即可显示服务端头像；失败时显示可理解的错误并允许使用同一暂存图片重试。
- [x] AC5. 移除操作不会与“取消待上传图片”混淆；确认对话框必须说明影响，取消确认不发起请求，确认后的成功、失败和冲突保持现有服务端语义。
- [x] AC6. App、移动 Web 和桌面 Web 使用一致的操作顺序与文案；窄屏无横向溢出、遮挡或过小触控目标，桌面端支持文件拖放。
- [x] AC7. 只读用户能查看头像但无法选择、上传、替换或移除。
- [x] AC8. 现有 Platform 头像 API、5 MiB 限制、认证、CSRF、乐观并发和私有对象访问测试继续通过。
- [x] AC9. 相关 Vitest、Playwright、格式化、lint、类型检查和生产构建通过，并对 App、移动与桌面视口保留可复核截图。

## Out of Scope

- 修改头像存储模型、API 路径、鉴权方式、对象可见性或上传大小限制。
- 重做账户菜单、个人资料字段、社区工作区导航或其他图片上传场景。
- 原生后台上传、上传进度百分比、相机拍摄能力或全局媒体缓存。
- 头像旋转、滤镜、自由比例裁剪或通用图片编辑器。

## Decisions

- D1. 选图后统一进入正方形手动裁剪，提供拖动、缩放和圆形结果预览。
- D2. 裁剪完成只生成待上传文件，不自动写入服务端；用户仍需明确执行上传。
- D3. 移除现有头像前显示确认对话框，并说明该操作会移除当前头像，包括账户关联的外部头像。
