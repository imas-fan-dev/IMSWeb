# 修复地图场景地点搜索

## Goal

修复事务所地点选择与公开地图地点搜索，验证查询、结果选择和地图定位。

## Requirements

- 事务所地点搜索支持按钮和 Enter；Enter 不提交外层事务所表单。
- 显示加载、错误、无结果和 attribution；选择地点仅更新城市、地址及精确坐标，保留其他草稿字段。
- 公开地图提供独立地点搜索；选择结果移动地图，并保留城市事务所筛选。
- 搜索使用服务器代理、显式提交、最多五条结果、24 小时共享缓存和全应用每秒一次上游限流。
- 未配置 provider 时明确提示服务未配置。公开查询只在公开读取和地图开关均开启时匿名可用；所有写权限保持原契约。
- 保留事务所所有者精确位置与公开区域化位置边界。
- 修复配置模板到运行时的必要连接；通过应用端点验证真实支持的 geocoder 查询，不部署或修改生产数据。

## Acceptance Criteria

- [x] 按钮和 Enter 均查询，且不保存事务所；加载、错误、空结果有明确反馈。
- [x] 选中事务所地点保留未保存字段；公开地图选择地点后更新地图范围。
- [x] 匿名公开地图搜索、关闭开关、私有查询认证、缓存、限流及位置隐私回归通过。
- [x] Compose 转发 geocoder 配置，真实 provider 查询经过应用端点并返回有用结果。
- [x] 桌面、移动及 App 浏览器验证和所需质量检查通过。原生设备验证不在本次浏览器证据范围内。

## Notes

- 用户已授权本子代理规划、启动、实现及验收；主会话负责最终验收和提交。
- Web 测试、构建和 Playwright 窗口由主会话调度，不与图片任务并行运行。
